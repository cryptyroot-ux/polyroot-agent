# Security Policy

## Supported Versions

We release frequent updates for security patches. The current active production release version (`v0.x`) is supported.

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability within PolyRoot, please report it responsibly. **Do not create a public GitHub issue.**

Instead, please send an email to security@cryptyroot.io or report via private GitHub security advisory.

- Provide a detailed description of the vulnerability.
- Include steps to reproduce or proof-of-concept code.
- Allow up to 48 hours for our team to acknowledge and coordinate remediation before any public disclosure.

## Security Practices

- Private keys, mnemonic phrases, and signing credentials are strictly isolated in local secure vaults and never transmitted or logged.
- All financial pathways require explicit vault sign-off and risk engine checks.
